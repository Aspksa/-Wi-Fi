# Wi Fi

Локальный монитор каналов Wi‑Fi для Windows 10 и 11. Первая версия помогает подобрать канал для Tenda RE3L в диапазонах 2,4 и 5 ГГц.

## Запуск

1. Скачайте ZIP в меню **Code → Download ZIP** и распакуйте его в любую папку.
2. Запустите **Wi-Fi.bat**. Используются встроенные Windows PowerShell и `netsh`. Нужен включённый Wi‑Fi-адаптер.
3. Чтобы отметить свой роутер на обоих диапазонах, введите точное имя своей сети (SSID). Без него программа выделяет точку, к которой сейчас подключена Windows.
4. Нажмите **Обновить** или оставьте окно открытым для фонового обновления каждые 30 секунд.

Если Windows ограничила доступ к сканированию, проверьте системные настройки доступа к местоположению для классических приложений и разрешения вашей учётной записи. Интерфейс программы русский. Сбор сетей рассчитан на русский и английский вывод Windows.

## Как читать результаты

- Список точек показывает основной канал и сигнал в процентах. Золотым выделяется своя сеть. Выбор строки канала фильтрует список точек. Кнопка **Все сети** сбрасывает фильтр.
- Баллы сравнивают вероятные помехи по каналам с учётом силы соседних сигналов. Чем ниже балл, тем спокойнее выглядит канал по одному замеру. Это оценка, а не доля занятого эфирного времени.
- На 2,4 ГГц сравниваются каналы 1, 6 и 11 с моделью ширины 20 МГц. На 5 ГГц каналы внутри одного предполагаемого блока 80 МГц имеют одинаковую оценку. Фактическую ширину и список доступных каналов проверьте в панели роутера. Сканер отображает оба диапазона, которые видит адаптер. Если Windows не указывает диапазон, приложение определяет его по номеру канала.
- Рекомендация появляется после трёх последовательных обновлений с одним кандидатом и расчётным улучшением от 30%.
- Первая версия работает в режиме наблюдения. Чтобы сменить канал, откройте `http://tendawifi.com/` из домашней сети, затем **Ещё → Настройки Wi‑Fi → Канал и ширина канала**. Поддержка автоматического переключения зависит от проверки конкретной прошивки RE3L.
