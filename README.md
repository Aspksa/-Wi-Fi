# Wi Fi

Локальный монитор каналов Wi‑Fi для Windows 10 и 11. Все показатели видны в одном окне. Программа помогает подобрать канал для Tenda RE3L в диапазонах 2,4 и 5 ГГц.

## Запуск

1. Скачайте ZIP через **Code → Download ZIP** и распакуйте его.
2. Запустите **Wi-Fi.bat**. Используются встроенные Windows PowerShell и `netsh`. Нужен включённый Wi‑Fi-адаптер. Поддерживается русский и английский вывод Windows.
3. Чтобы отметить свою сеть в обоих диапазонах, введите её точное имя в поле **Своя сеть** и нажмите Enter. Пустое поле позволяет выделить подключённую точку по её адресу.
4. Оставьте окно открытым для замеров каждые 30 секунд. Кнопка **Обновить** запускает замер вручную.

Если Windows блокирует сканирование, проверьте разрешения на определение местоположения для классических приложений и права учётной записи.

## Главный экран

- **Диагностика.** По три ICMP-запроса до IPv4-шлюза Wi‑Fi и до `1.1.1.1`, если маршрут к нему проходит через Wi‑Fi. Даже при исправной сети отдельный адрес может фильтровать ICMP. Замеры помогают искать источник лагов, а точную причину помогают уточнить другие измерения.
- **Карты 2,4 и 5 ГГц.** Чем выше столбец, тем сильнее расчётные помехи от видимых соседних точек. Золотой контур выделяет свой канал. Под картами видны кандидаты на смену. Для рекомендации нужны три последовательных замера с одним кандидатом и улучшением текущей оценки минимум на 30%. Когда задержка или потери видны только до внешнего адреса, совет о смене откладывается.
- **Точки доступа.** Выберите соседнюю точку и нажмите **Следить**. Программа запоминает BSSID и диапазон, поэтому различает несколько точек с одинаковым именем. В журнале появятся смены канала и переходы в состояние расчётного пересечения со своей сетью.
- **История.** Две строки тепловой карты показывают среднюю оценку помех на собственных каналах за каждый из последних 24 часов. Серый цвет означает отсутствие замера. История каналов для сравнения по часам хранится до семи дней, журнал содержит до 100 событий. Данные записываются локально в `%LOCALAPPDATA%\Wi Fi\history.json`.

Баллы рассчитываются по силе соседних сигналов и предполагаемому перекрытию. Для 2,4 ГГц используются модель полосы 20 МГц и кандидаты 1, 6 и 11. Для 5 ГГц программа группирует каналы внутри предполагаемых блоков 80 МГц. Это оценка, а не занятость эфира или измеренная ширина полосы. Статистика за тот же час предыдущих дней помогает упорядочить кандидатов с близкими баллами. Проверьте доступность предложенного канала в панели роутера.

Менять каналы можно вручную через `http://tendawifi.com/` в домашней сети. Откройте **Ещё → Настройки Wi‑Fi → Канал и ширина канала**. Автоматическая смена канала зависит от прошивки Tenda RE3L.
