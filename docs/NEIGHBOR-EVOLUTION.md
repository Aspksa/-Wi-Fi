# Wi-Fi v2.4 · наблюдения соседних сетей во времени

Модуль `NeighborTracking.ps1` добавляет анализ соседей между **завершёнными активными** сканированиями Windows WLAN. Обычное чтение кэша BSSID, `netsh` и неподтверждённый импорт не считаются независимыми наблюдениями.

- 1 успешное наблюдение: впервые замеченная точка, без вывода о её стабильности.
- 2 успешных наблюдения: предварительное присутствие.
- 3 и более: устойчивая точка **в пределах текущей сессии**, без утверждений о её владельце или местоположении.
- Смена канала BSSID фиксируется как наблюдаемое событие, но не как доказательство, что сосед изменил настройки вручную.
- После 2 подряд завершённых сканирований без точки она помечается `не наблюдалась`. Это **не доказывает**, что сеть исчезла физически.
- Неоднозначные, старые и невалидные данные исключаются. При смене сетевого шлюза счётчики сбрасываются; хранение ограничено 500 точками и последними 20 событиями.

В единой карте доступны сводка по диапазонам, устойчивость наблюдений, смены каналов и ограничения достоверности. Сохраняются SQLite, `Wi-Fi.bat`, PowerShell 5.1, UTF-8 BOM и прежние алгоритмы оценки перекрытий. Никаких новых зависимостей и команд изменения роутера нет.

**Что невозможно решить только программно:** Windows может запрещать сканирование, не показывать некоторые диапазоны или возвращать кэшированные BSSID. Для настоящего радиочастотного спектрального анализа нужны поддерживающее оборудование и драйвер; программа не подменяет аппаратные измерения расчётами.
