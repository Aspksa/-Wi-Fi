# Tenda RE3L: проверка и безопасная интеграция

## Ограничения и безопасность

Версия проекта **не имеет подтвержденного API для сканирования или установки каналов RE3L**. Официальное руководство описывает настройку через локальную веб-панель, но не публикует совместимый API. Эндпоинты других моделей Tenda (AC10, Mesh, умных розеток) **не следует** автоматически применять к RE3L.

Программа проверяет локальный IPv4-шлюз Wi-Fi и только корневую страницу по HTTP без входа в учётную запись. Если веб-панель требует авторизацию, данные о прошивке могут оставаться неизвестными. Автоматическая смена канала и откат **заблокированы до появления испытанного драйвера с проверяемым возвратом**. Это не скрытая возможность, которую можно включить настройкой.

## Резервный импорт сведений о радиоэфире

Если панель RE3L (после обычного входа пользователем) показывает соседние точки и позволяет экспортировать наблюдения, можно создать файл:

`%LOCALAPPDATA%\Wi Fi\router-telemetry.json`

Пример **формата**, а не реальные измерения или автоматически полученный вывод RE3L:

```json
{
  "routerAddress": "192.168.0.1",
  "model": "RE3L",
  "firmware": "V16.03.60.62",
  "capturedAt": "2026-11-18T12:00:00Z",
  "networks": [
    {"ssid":"Home","bssid":"aa:bb:cc:dd:ee:01","band":"2.4","channel":6,"rssi":-48,"widthMhz":20,"own":true}
  ],
  "airtime": [
    {"band":"2.4","channel":6,"busyPercent":32,"source":"radio-airtime-counter"}
  ]
}
```

Замените все примерные значения на реально полученные данные, **не добавляйте поле airtime, если роутер не показывает аппаратный счётчик занятости эфира**. Значение времени должно быть фактическим временем замера в ISO 8601. Данные принимаются только для текущего локального адреса роутера, RE3L, не старше 60 секунд. Импорт не даёт мониторинг 24/7 сам по себе и помечается как **неподтверждённый источник**. Файл не должен содержать логин, пароль, токены, cookies, серийный номер или MAC самого устройства.

Если Windows разрешает сканирование, она остаётся основным источником. Если блокирует, пригодный свежий экспорт используется для резервной карты каналов, но **не** для автоматического переключения или подтверждения рекомендаций.

## Анализ причин и история

Существующие SQLite таблицы `samples`, `radio_scans`, `channel_trials` и `context_checks` сохраняются. Результаты смены каналов учитываются через `Get-TrialMemory`. На веб-странице отдельно показаны расчётная оценка перекрытия, реальная задержка до шлюза и внешнего адреса, и наличие или отсутствие счётчиков эфирного времени. Без подтверждённого аппаратного счётчика нельзя называть перекрытие «реальной загрузкой».

## Проверки на Windows

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\PowerShellSyntax.Tests.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\RouterTelemetry.Tests.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\RouterDiscovery.Tests.ps1
Wi-Fi.bat web
```

Роутер, который фактически предоставляет проверенные read-only JSON данные, можно поддержать отдельным драйвером после документирования формата ответа, авторизации и контрольного теста на конкретной прошивке. Для управления потребуются дополнительное согласие, проверка текущего канала, защита от потери связи, лимиты попыток и испытанный механизм отката.
