# Wi-Fi v2.5 — Intelligent Spectrum Scanner

Программа продолжает использовать Windows WLAN API, netsh как резервный источник и локальную SQLite, без прошивки роутера и без изменения его настроек.

## Качество сканирования
- Доступность сканирования определяется по результатам Windows. Когда блокировка подтверждена, пользователь видит инструкцию по проверке службы геолокации и WLAN AutoConfig. Проверка не может достоверно установить, какой конкретный системный переключатель выключен, поэтому не заявляет этого.
- Адаптивная пауза между циклами: 20 секунд при зафиксированной проблеме соединения, 30 секунд по умолчанию, 60 секунд при стабильных наблюдениях, до 120 секунд при ошибках или блокировке. Принудительное сканирование выполняется реже, чем пассивное получение снимка (сохранено исходное ограничение); программа не обходит Windows.
- Различаются завершённый скан Windows WLAN, пассивные/неполные снимки, netsh с неподтверждённой свежестью и устаревшие результаты. Трекер BSSID дополнительно проверяет собственное время наблюдения каждой точки, чтобы повторное чтение кэша не считалось новым событием.

## Аналитика
- Существующий алгоритм пересечения учитывает геометрию каналов, а отдельная панель показывает рейтинг силы наблюдаемых соседей по сигналу и признак подтверждённой/неизвестной ширины полосы. **Это не аппаратное измерение загрузки эфира** и не физическая диагностика скрытых источников помех.
- В рамках сессии трекер хранит численность наблюдений, средний сигнал, резкие скачки (от 25 процентных пунктов) и повторяющиеся смены канала BSSID. Изменение сигнала может быть вызвано положением клиента, а не неисправностью соседа.
- По сохранённым SQLite-сканам программа сравнивает среднее число соседей по UTC-часам за последние 48 часов; рядом выводится процент проблемных локальных проб, если их достаточно. **Корреляция и причинная связь не доказаны**.
- Рекомендация перейти к **ручному испытанию канала** возможна только после старых строгих проверок плюс 3 завершённых независимых наблюдения и свежий подтверждённый снимок. Автоматическая смена канала и откат отключены.

## Диагностика адаптера
Интерфейс показывает доступные Windows сведения об имени, описании и номинальной скорости адаптера. Версия драйвера и поддержка диапазонов помечены как *не проверены*, если надёжных системных данных нет; никаких выдуманных характеристик.

## Безопасность и совместимость
Сохранены `Wi-Fi.bat`, единственная страница, существующие истории SQLite, Windows PowerShell 5.1 и UTF-8 BOM. Новых зависимостей, Docker, роутерных запросов изменения настроек или обхода Windows нет. Расширения 6 ГГц и аппаратного спектрального анализа не заявлены без соответствующего драйвера и оборудования.

Проверка: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\SpectrumV25.Tests.ps1`.
