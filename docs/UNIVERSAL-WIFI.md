# Универсальный монитор Wi-Fi v2.2

Приложение работает без получения версии прошивки и без входа в панель управления роутера.

## Источники
1. **Windows WLAN API:** наблюдаемые соседние сети, сигнал, канал, BSSID и по возможности ширина. Это сведения о точках, а не точный аппаратный процент занятости эфира.
2. **netsh:** резервный системный источник; возраст наблюдений может быть неизвестен, поэтому рекомендации остаются предварительными.
3. **Локальный импорт:** существующий дополнительный файл `%LOCALAPPDATA%\Wi Fi\router-telemetry.json` применяется в ранее поддерживаемом формате, если он доступен и свеж. Он не обязателен и никогда не считается подтверждённой аппаратной загрузкой эфира. При отсутствии источников карта честно сообщает, что сканирование недоступно.

## Функции
- По IP локального шлюза и диагностическим замерам показывается доступность роутера, без проверки модели или прошивки.
- Пересечения каналов, их ширина и история SQLite участвуют в предварительном рейтинге; отдельные ограничения требуют свежего WLAN-снимка, повторных подтверждений и достаточного количества локальных проб.
- Различаются локальные и внешние сетевые проблемы, ведётся история изменений канала с измерениями до и после ручного переключения.
- Статистические тенденции вычисляются по последовательным интервалам наблюдений; повторяющиеся проблемные часы ищутся по нескольким дням. Эти выводы не доказывают причину.
- За время работы программы зависший сканер перезапускается. Все данные продолжают храниться в существующей SQLite.
- Единая карта показывает обнаруженные сети, каналы, задержки, тренды, историю, достоверность и ограничения рекомендаций.

## Безопасность
Автоматическая смена канала **не поддерживается** на произвольных роутерах без проверенного интерфейса, подтверждения пользователя и испытанного восстановления связи. Команд записи или автоматического отката нет. Программа не обходит ограничения Windows WLAN API.

## Проверка Windows
Запуск `Wi-Fi.bat web`. Проверки CI выполняются на Windows PowerShell 5.1, включая синтаксис, UTF-8 BOM, SQLite и веб-тесты. Новых обязательных зависимостей не добавлено.
