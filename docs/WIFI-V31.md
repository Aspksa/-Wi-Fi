# Wi-Fi v3.1 — надёжность, наблюдаемый 6 ГГц и долговременная память

Реализовано: периодический разрешённый retry полного WLAN-скана при блокировке (не чаще 120 секунд), ограничения повторов и классификация отказов, выбор Wi-Fi адаптера по GUID, инвентаризация локальных адаптеров и статуса диапазонов. Добавлены 6-ГГц частоты (5935 МГц канал 2, 5955–7115 МГц каналы 1–233) и третья 2D/объёмная Canvas-карта. Если драйвер не даёт данных, не рисуются выдуманные точки. Неизвестная ширина полосы не объявляется подтверждённой.

Долговременная память: агрегирование качества в hourly_quality и daily_quality (перед удалением сырых данных), срок хранения 31 день для почасовых и 366 дней для суточных рядов. Без изменения двухдневной политики сырой истории. SQLite backup использует sqlite3_backup API и PRAGMA integrity_check; до пяти копий, обновление каждые пять часов. **Автовосстановление живой БД не включается**: восстановление требует отдельного действия с сохранением оригинала.

Импорт PCAPNG: только сохранённые разрешённые файлы little-endian SHB/IDB/EPB; строгие ограничения на размеры и число кадров; поддерживаются IEEE 802.11 и radiotap через прежний безопасный офлайн-PCAP декодер. Не захватывает радиоэфир.

Расследования: BSSID, RSSI, изменённые объявленные характеристики, ограниченные события и уведомления (не чаще одного за пять минут); локальные HTML/JSON-отчёты с экранированием пользовательских строк, диагностические метрики CPU/памяти процесса. Гипотезы не заявляют доказанную причину помех или подмену сети. Самотест проверяет веб-файлы, наличие сканера и SQLite integrity_check, но не гарантирует фактическое радиосканирование.

**Условные возможности:** полноценное обнаружение чужих Wi-Fi Direct устройств и активный Monitor Capture не включены: для этого нужны подтверждённые поддерживаемые драйвер и интерфейс. Не устанавливаются драйверы, нет обхода Windows, deauth, изменений роутера, Docker или новых обязательных зависимостей.

Совместимость: Windows PowerShell 5.1, UTF-8 BOM, Wi-Fi.bat, SQLite, одно веб-окно. Настоящую совместимость встроенного адаптера с 6 ГГц нужно проверить на пользовательском оборудовании, GitHub Actions это не измеряет.

Команды тестирования: powershell.exe -File tests/WifiV31.Tests.ps1 ; PcapInspect.ps1 -Path "путь_к_файлу.pcapng"
